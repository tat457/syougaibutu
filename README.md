# SkySprint Motion OBBY

ローカルで動く、Webカメラ姿勢認識型の体感OBBYゲームです。カメラ映像はブラウザ内で処理され、サーバーへ送信しません。初回のみMediaPipeの姿勢認識モデルをCDNから取得します。

## 起動

このフォルダで次を実行し、表示された `http://localhost:8000` をChromeまたはEdgeで開きます。

```sh
python3 -m http.server 8000
```

「カメラをつないでスタート」を押してカメラを許可し、全身が映る状態で数秒間まっすぐ立ってください。映像の指示に合わせ、ジャンプ、左右移動、しゃがみを判定します。
